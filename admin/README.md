# VFoot Arena — Interface Administrateur (C++)

Interface console C++ pour l'administration de la plateforme.

## Responsabilités
- Gérer les comptes utilisateurs
- Bannir / débannir des joueurs
- Superviser toutes les cups
- Gérer les trophées

## Base de données partagée
`efootball_tournament` — voir `/database/efootball_tournament_v2.sql`
